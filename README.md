# Biệt Thự Bóng Tối — Villa of Darkness

Horror exploration game built with Unity 6 + URP.

**Studio:** Fictional Station Studio  
**Engine:** Unity 6 | URP | C#

## Setup

1. Clone repo
2. Open in Unity 6 (URP)
3. Open scene: `Assets/_Project/Scenes/MainMenu.unity`
4. Press Play

## Team branches

`phase2.7/detail/<username>` — detail pass on Chapter1  
`phaseX/feature/<slug>` — new features

## Build

Build Settings: MainMenu (index 0) → Chapter1 (index 1)
